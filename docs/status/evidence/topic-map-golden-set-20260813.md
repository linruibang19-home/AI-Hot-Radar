## 已验证行为

- 固定 seed、内容 ID、revision ID、正文 SHA-256 和总体分层规模；
- 空分层也进入 `strata`，不会被“没有样本”静默隐藏；
- 任意待审核标签存在时状态为 `pending_human_review`；
- `evaluate` 在待审核状态退出码为 2，不输出部分指标；
- 按分层总体规模做逆抽样概率加权，避免 2 条的小分层和 2000 条的大分层各占同样权重；
- 两份复核包隐藏生产预测、置信度和规则原因，并以不同确定性顺序呈现；
- 同一复核人、证据字段改写、未完成双审、未裁决分歧和原复核人自行裁决都会被拒绝；
- 对厂商与主题分别输出一致率和 Cohen's κ，避免类别分布偏斜掩盖低于偶然水平的可靠性；
- 完成后同时输出含完整审计上下文的本地集与不含第三方正文摘录的标签归档，并计算分层
  bootstrap 95% 置信区间；
- 候选队列含第三方原文摘录，已加入 `.gitignore`，不会进入公开仓库。
