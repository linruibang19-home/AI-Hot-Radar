## 5. RAG 当前完整流程

```text
问题与会话上下文
-> 确定性 Planner（实体、别名、意图、相对时间转绝对区间）
-> dense pgvector + sparse tsvector + entity/temporal 多路召回
-> 加权 RRF
-> bge-reranker-v2-m3 交叉编码器重排
-> directness / source_fit / temporal_fit 等确定性调整
-> 同篇限流、同 Story 折叠、来源多样性、父块上下文扩展
-> DeepSeek 结构化生成（问题与原始证据均放入不可信数据边界）
-> 服务端反查引用
-> 段落支持度门禁
-> 删除无引用事实句、清理孤儿引用与重编号
-> 高风险数值关系审计
-> 凭据形态 fail-closed
-> 不变量校验、拒答或落库
-> SSE/永久链接/可解释检索轨迹
```
