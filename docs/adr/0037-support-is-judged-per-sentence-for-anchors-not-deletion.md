# ADR-0037：逐句判定支持度——用于选段落和评测，不用于删句

- 状态：已接受
- 日期：2026-09-24
- 修订：ADR-0035 决策第 1、2 条（锚点按每条引用的 `claim_text` 选 → 按引用它的每一句选）
- 相关：ADR-0016、ADR-0023、ADR-0035

## 背景

支持度门控、生成评测和 ADR-0035 的锚点选择，都只拿每条引用的一句 `claim_text` 打分。
而一个 `[n]` 常被多句话共用：FROZEN 冻结基线 272 条引用里 155 条被两句以上共用。
浏览器实例：「智谱完成约 50 亿美元融资 [1]」，[1] 被打分的是另一句，锚点分块里也没有这个数字。

读者核对的单位是「一句话 × 它带的一个 `[n]`」。FROZEN 已发布 685 对，逐对补测：
按模型读到的上下文（父块）达标 0.9168，按悬停显示的检索分块达标 0.8613——
而评测页的每条引用口径是 0.97。

## 决策

1. **锚点按引用它的每一句选。** 候选仍是 ADR-0035 限定的 `document` / `section` 层可见兄弟分块。
   命中分块支持它的全部句子就不动；否则取支持句数最多的候选（同数比总分），且必须严格优于命中。
   每句一次 rerank 请求（该句对兄弟分块），与支持度打分并发；任一请求失败则该引用保留原锚点。
   没有正文标记、只来自 `claims` 的引用，以其 `claim_text` 作为唯一句子。
2. **不据此删句。** 逐句低分不删除标记、不删除句子（理由见证据第二部分）。门控仍是 ADR-0023
   的每条引用口径。
3. **评测新增逐句口径**：`sentence_pairs`、`sentence_support_supported`（悬停段落）、
   `sentence_support_as_read_supported`（父块），按对汇总而不是按题平均。原有
   `support_*` 保留，历史序列可比。
4. **页面说清口径**：`/eval` 的段落支持达标率旁注明「每条引用一句」并给出逐句数字（由
   `scripts/build_eval_summary.py` 从逐对数据推导，不写死）；线上对照行注明两栏口径不同、
   右栏是门控之后的结果；问答页支持度提示改为「这条引用所配的一句论断 × 模型读到的上下文」。

## 证据（2026-09-24，本地，FROZEN 冻结基线，BAAI/bge-reranker-v2-m3，阈值 0.30）

逐对数据：`data/eval-runs/sentence-support-pairs-20260924.json`（每对对父块、命中分块、
每个兄弟分块的分数，以及按本决策选出的锚点与其分数）。打分 0 次失败。

**一、按句选锚点**（全部 685 对，段落级达标）：

| 锚点选择 | 达标 |
|---|---:|
| 检索命中分块 | 0.8613 |
| 按 `claim_text`（ADR-0035 原版） | 0.8701 |
| **按引用它的每一句** | **0.8993** |

用生产代码 `choose_anchors` 重放复现 0.8993：移动 24 条，每个答案平均 2.2 次 rerank 请求，
0 条告警（由逐对分数离线推导为 25 条，一处近乎持平的边界在两次请求间翻转，达标率不变）。

**二、逐句删除被否决。** 严格策略（不支撑就摘掉该句的该标记，句子无标记则删除，永不删空）：
30 / 90 个答案受影响，删 23 句，0 个答案被删空，must_contain 24/24 保留。但 23 句逐条回原文核对
（模型辅助，原文片段可复查）：至少 14 句原文里有（6 句数字全部出现在原文），3 句是「证据中没有……」
式否认，约 6 句是推断或边界。**删除准确率最多约 26%。** 交叉编码器是相关性模型，逐句粒度上系统性
低估长句、英文原文的中文转述和短句，不能用来删内容。否认句豁免的变体结果相近（删 21 句）。

**三、端到端**：3 题生成评测跑通新指标（26 对，0 条告警）；样本太小，数字不作结论。

## 后果

- 有兄弟分块的引用，rerank 请求从每条 1 次变为每句 1 次（FROZEN 上平均每答 2.2 次），并发，不增加串行往返。
- 评测每题多约 7.6 次顺序 rerank 请求（每对一次，两种口径同一请求）。
- 删除没依据的句子仍是空缺：需要换蕴含模型或 LLM 判官，并先在这 685 对上测出准确率再谈上线。

## 回滚

`service.answer_question` 里把 `sentences_by_citation(text, citations)` 换回
`{c.chunk_id: [c.claim_text] for c in citations}` 即恢复 ADR-0035 原版；评测新字段可留。
