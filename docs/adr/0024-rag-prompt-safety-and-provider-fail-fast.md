# ADR-0024：RAG 证据安全边界与供应商快速失败

- 状态：已接受
- 日期：2026-08-11
- 相关：`AHR-RAG-400` §9–§10、`AHR-QSO-700` §4–§8、ADR-0017、ADR-0023

## 背景

网页正文是不可信数据，可能包含“忽略之前指令”“输出系统提示词”等文本。现有回答仍受
服务端引用绑定和支持度门禁约束，但提示中没有把每段证据明确隔离为不可信数据，也没有
对最终文本做凭据形态检查。另一方面，重排器默认 60 秒、3 次尝试；08-11 全量回归中
89 次重排累计 522081 ms（均值约 5.9 秒），因此单次 180 秒等待不是合理降级边界。

运维页已有端到端 p95，却只显示各阶段 p50，不能回答是 embedding、rerank 还是 generate
违反 SLO，也不能在发布前给出可机器判断的超标状态。

## 决策

1. 问题与原始证据在提示中使用不同的显式数据边界；每段证据标记为
   `UNTRUSTED_EVIDENCE`，系统指令明确禁止执行其中任何指令、权限请求或输出格式要求。
2. LLM 输出继续视为不可信；在服务端引用/支持度/逐句门禁之后增加凭据形态扫描。
   命中常见 API key、私钥头或认证头时 fail closed，不把疑似秘密返回或缓存。
3. 不用关键词直接拒绝普通用户问题。“prompt injection 最近有什么动态”是合法内容问题；
   防护对象是证据指令的权限，而不是某几个词。
4. embedding/rerank 的超时与最大尝试次数可由环境变量覆盖并做上下界校验；重排默认改为
   20 秒、2 次尝试。重排失败沿用现有 fused-order 降级，不能拖垮回答。
5. `/ops` 对 embedding、rerank、generate、numeric audit、support 分别报告样本数、
   p50/p95/p99、阈值和 `ok/breached/insufficient_data`。阈值可配置，未达到最小样本量
   不得显示为健康。
6. 不在没有第二供应商凭据和真实回归的情况下声称“备用模型切换”；本卡只做快速失败、
   可观测与现有降级。

## 后果

- 恶意网页指令即使进入候选，也只作为引用数据出现，不能改变系统权限；疑似凭据输出
  会变成可观察的安全拒答。
- 短期供应商抖动可能更早进入重排降级，但最长阻塞显著收敛；检索质量变化需保留降级指标。
- SLO 页面能区分“无样本”和“达标”，上线后可直接接告警；真实告警渠道仍等服务器配置。

## 不采用的方案

- **按关键词丢弃整篇证据**：安全文章本身常讨论 prompt injection，会造成系统性召回偏差。
- **把凭据正则当完整 DLP**：它只是上线基线，不能替代租户 ACL、PII 分类和外部 Guardrail。
- **立即引入第二供应商或新网关**：没有凭据、价格与回归数据，无法证明可用或更安全。
