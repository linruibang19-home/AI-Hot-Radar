# ADR-0020：`abstention accuracy` measures 行为，不再 measures 回答形态

- 状态：已接受
- 日期：2026-08-09
- 相关：`AHR-QSO-700` §8（RAG 发布门禁：空答案/诱导题 abstention accuracy ≥ 0.90）、`AHR-RAG-400` §14、3.13（拒答给出路）、3.23 ①（判官轮）

## 背景

`AHR-QSO-700` §8 要求「空答案/诱导题 abstention accuracy ≥ 0.90」，
但**没有定义这个数怎么算**。实现里它一直是
`refusal_rate_on_unanswerable = 拒答题数 / 不可答题数`，
而「拒答」被定义为 `answer_markdown` 为空或引用数为 0。

3.13 随后刻意改掉了死胡同式拒答：读者拿到的不再是一句
「没有足够证据回答这个问题」，而是**有据可查的否认**——
「证据里没有提到罚款，也没有任何监管机构开出罚单的记载」，并列出检索到的内容。
这个改动是对的，它给了读者去路。

**但它让旧指标读数崩了，而系统能力没有任何变化。** 有据否认**有正文、有引用**，
于是被判成「没有拒答」。实测读数：

| 轮次 | `refusal_rate_on_unanswerable` |
|---|---:|
| 20260804 | 0.6667 |
| 20260807 | 0.2500 |
| 20260807-judged | 0.0833 |
| 20260807-fixed | **0.0000** |
| 20260809-gated | **0.0000** |

一路跌到 0，而同期**没有任何一道诱导题被答错**。
另一个辅助信号 `must_not_claim` 是子串匹配，它自己的注释就写着
「否认时提到该词也算命中」，且只覆盖 15 题里的 4 题。

**两个信号测的都是回答长什么样，不是它说了什么。**

## 决策

**`abstention accuracy` 的判据改为 `presupposition_asserted_rate`，
即「在诱导题上断言了假前提的比例」，门禁读作 `1 − presupposition_asserted_rate ≥ 0.90`。**

判定由**受控二值判官**给出：只看「回答」与「假前提」两段文本，
不看证据、不看引用，输出一个词。假前提写进黄金集，与题目一起版本化。

三条配套约束，缺一条这个指标就会变回可被形态糊弄的东西：

1. **必须与误拒率一起读。** 一个全都拒答的系统在本指标上满分且毫无用处。
   当前 `over_refusal_rate = 0.0000`（78 道可答题零误拒），两个数同时成立才算达标。
2. **判官不看证据。** 让判官看证据就变成了第二个 RAG 系统在评价第一个，
   两者的失败会相关，而相关的失败测不出东西。
3. **旧指标保留在报告里，但不再作为门禁判据。** 它仍然回答一个真实问题
   （「有多少回答是空的」），只是那个问题不是 §8 问的那个。

## 后果

- `AHR-QSO-700` §8 的字面**未修改**，本 ADR 是它的判据定义。
  规格优先级高于设计文档，因此这条定义必须以 ADR 形式存在，
  而不能只写在 `m4-rag-evaluation.md` 里——那是本项目已经踩过的坑：
  十三轮检索评测与四轮生成评测**没有一处对照过 §8**，
  部分原因就是判据散在实现文档里、没有一个权威落点。
- 报告中出现 `abstention accuracy` 时**必须注明取的是哪个量**。
  在此之前，「这条门禁过没过」取决于读者选哪个指标——
  **0.0000 和 1.0000 都能从同一份 JSON 里查出来**。

## 已知局限（写在前面，不等被问）

**样本量 12 道，分辨不出 0.85 与 0.95。** `abstention` 类共 15 题，
其中 3 道是「部分可答」（C 型，088/089/090），`answerable: true`，
正确行为是答一半并明说缺口——这个设计是对的（只测该拒的题会训练出动辄拒答的系统），
代价是严格意义的不可答样本只剩 12 道。**每错一题就是 8.3 个百分点。**

因此当前 `presupposition_asserted_rate = 0.0000（12/12）` 支持的结论是
「没有观测到断言假前提」，**不是**「达到了 0.90 以上的置信区间」。
门禁要真正判定通过，**先把不可答样本扩到 30 题以上**，已列为任务卡。
